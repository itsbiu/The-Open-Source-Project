¿Qué es Matrix?

Matrix es un servicio de mensajería instantánea libre y descentralizado. Si bien tienen sus propios servidores en matrix.org, puedes montar tu propio servidor Matrix como hemos hecho nosotros, donde puedes manejar todos tus datos y dependes de ti mismo para tu privacidad.

Hemos elegido Matrix ya que es un servicio bastante conocido en la actualidad. Si bien muchas personas no le dan preferencia al ser un servicio que no tanta gente utiliza y que mucha gente ya está acostumbrada a redes como Discord o WhatsApp, estas se quedan con tus datos y los venden para obtener beneficios. En Matrix todo se queda donde está hosteado y el riesgo para tu privacidad es mucho más bajo.

  • Mensajería cifrada de extremo a extremo
  • Tus conversaciones en tus propios servidores
  • Sin venta de datos ni publicidad
  • Protocolo abierto e interoperable

Requisitos previos

Lo que necesitas antes de empezar la instalación

Ubuntu Server

Máquina virtual con Ubuntu Server 24.04.4 LTS. En nuestro caso corre sobre IsardVDI con IP 192.168.101.50.

Red configurada

La red interna 192.168.101.0/24 debe estar operativa, con Kea DHCP y Bind9 funcionando correctamente.

Acceso root

Necesitas acceso con permisos de superusuario para instalar paquetes y modificar archivos de configuración del sistema.

Caddy / HTTPS

Recomendable tener Caddy configurado para servir Matrix con HTTPS a través de la función bastion de IsardVDI.
