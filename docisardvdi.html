IsardVDI — Núcleo del proyecto

Plataforma de virtualización de escritorios que aloja todas las máquinas virtuales del proyecto y las hace accesibles remotamente.

¿Qué es IsardVDI?

IsardVDI es una plataforma de virtualización de escritorios de código abierto. En nuestro proyecto actúa como el núcleo central, alojando todas las máquinas virtuales con Ubuntu Server 24.04.4 LTS que ejecutan cada uno de los servicios.

A diferencia de VirtualBox, IsardVDI permite trabajar en el proyecto desde cualquier lugar sin depender de un equipo físico específico, ya que las máquinas virtuales son accesibles de forma remota a través del navegador.

Ventajas principales
  • Acceso remoto desde cualquier lugar sin VPN adicional.
  • Si una falla, las demás siguen operativas.
  • Plantillas disponibles de Ubuntu Desktop y Ubuntu Server, evitando reinstalaciones constantes.
  • No depende del equipo local.
  • Ubuntu 24.04 server como sistema operativo base, estable y funcional.
Redes utilizadas

Las máquinas virtuales del proyecto están conectadas a las siguientes redes de IsardVDI:

  • puigcastellar5 — Red interna del proyecto (192.168.101.0/24). Aquí se conectan Kea, Bind9, Nextcloud y Matrix.
  • puigcastellar1 — Red del instituto con salida a internet. El gateway y la página web también están conectados aquí.
El gateway tiene interfaz en ambas redes para proporcionar conectividad a internet a los clientes de la red interna.
Estructura de máquinas virtuales
  • VM Kea DHCP — Asigna IPs a los clientes de la red 192.168.101.0/24.
  • VM Bind9 DNS — Resuelve dominios locales (192.168.101.20).
  • VM Nextcloud — Almacenamiento y compartición de recursos (192.168.101.40).
  • VM Matrix — Mensajería instantánea (192.168.101.50).
  • VM Página web - Información y documentación (192.168.101.1).
