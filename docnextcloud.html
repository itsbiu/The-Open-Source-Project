Nextcloud — Nube privada

Instalación de Nextcloud con Apache2, MySQL y PHP en Ubuntu Server para un almacenamiento en la nube completamente privado.

Descarga e instalación de dependencias

Descarga la última versión de Nextcloud e instala Apache2 y MySQL:

wget https://download.nextcloud.com/server/releases/nextcloud-33.0.2.zip
sudo apt install -y apache2
sudo apt install -y mysql-server
Instalación de módulos PHP

Instala los paquetes PHP necesarios para que Nextcloud funcione correctamente:

sudo apt install -y php libapache2-mod-php php-fpm php-common \
  php-mbstring php-xmlrpc php-soap php-gd php-xml php-intl \
  php-mysql php-cli php-ldap php-zip php-curl
Nextcloud es compatible con la versión de PHP incluida en Ubuntu Server 24.04, por lo que no es necesario añadir repositorios adicionales.
Configuración de la base de datos

Accede a MySQL y crea la base de datos y el usuario para Nextcloud:

mysql
CREATE DATABASE bbdd;
CREATE USER 'usuario'@'localhost' IDENTIFIED WITH
  mysql_native_password BY 'password';
GRANT ALL PRIVILEGES ON bbdd.* TO 'usuario'@'localhost';
FLUSH PRIVILEGES;
EXIT;
Despliegue de los archivos

Mueve el ZIP descargado a /var/www/html, descomprímelo y organiza los archivos:

mv nextcloud-33.0.2.zip /var/www/html/
cd /var/www/html/
unzip nextcloud-33.0.2.zip
rm nextcloud-33.0.2.zip
mv nextcloud/* .
rmdir nextcloud
Permisos y reinicio de Apache2

Asigna los permisos correctos y reinicia el servidor web:

sudo chown -R www-data:www-data /var/www/html/
sudo chmod -R 755 /var/www/html/
sudo systemctl restart apache2
Después de estos pasos, accede a http://cloud.tosp.local.net desde un navegador dentro de la red para completar la instalación vía interfaz web.
