Kea DHCP — Asignación de IPs

Configuración del servidor DHCP Kea para la red 192.168.101.0/24, con reservas estáticas y pool dinámico.

Instalación

Actualiza los repositorios e instala el servidor DHCP de Kea:

sudo apt update && sudo apt install kea-dhcp4-server -y
Configuración básica

Edita el archivo /etc/kea/kea-dhcp4.conf con la siguiente configuración completa:

{
  "Dhcp4": {
    "interfaces-config": {
      "interfaces": ["enp2s0"],
      "dhcp-socket-type": "raw"
    },
    "reservations-global": false,
    "reservations-out-of-pool": true,
    "valid-lifetime": 86400,
    "renew-timer": 43200,
    "rebind-timer": 75600,
    "subnet4": [
      {
        "subnet": "192.168.101.0/24",
        "match-client-id": false,
        "option-data": [
          { "name": "routers",            "data": "192.168.101.10" },
          { "name": "domain-name-servers","data": "192.168.101.20" },
          { "name": "domain-name",        "data": "network.tosp.local.net" }
        ],
        "pools": [
          { "pool": "192.168.101.150-192.168.101.254" }
        ],
        "reservations": [
          {
            "hostname":   "host1.network.tosp.local.net",
            "hw-address": "52:54:00:10:82:ce",
            "ip-address": "192.168.101.100"
          },
          {
            "hostname":   "host2.network.tosp.local.net",
            "hw-address": "52:54:00:7e:98:64",
            "ip-address": "192.168.101.101"
          }
        ]
      }
    ],
    "loggers": [
      { "name": "*", "severity": "DEBUG" }
    ]
  }
}
Explicación de parámetros clave
  • dhcp-socket-type: raw — Ideal para redes con dispositivos sin IP asignada previamente.
  • reservations-global: false — Las reservas solo aplican a la subred definida.
  • reservations-out-of-pool: true — Permite reservas fuera del rango del pool dinámico.
  • valid-lifetime: 86400 — La IP asignada es válida durante 24 horas (en segundos).
  • renew-timer: 43200 — El cliente renueva la IP a las 12 horas.
  • pool: 150–254 — Rango dinámico para clientes sin reserva.
Activar y verificar el servicio
sudo systemctl enable kea-dhcp4-server
sudo systemctl restart kea-dhcp4-server
sudo systemctl status kea-dhcp4-server
Si el estado es active (running), el servidor DHCP está operativo y asignará IPs automáticamente a los dispositivos que se conecten a la red.
