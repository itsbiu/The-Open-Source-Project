Bind9 — Servidor DNS

Guía de instalación y configuración del servidor DNS Bind9 para la red tosp.local.net.

Instalación

Para instalar Bind9 en Ubuntu Server, ejecuta el siguiente comando:

sudo apt install bind9 -y
Configuración de la zona DNS

Edita el archivo /etc/bind/named.conf.local y añade la definición de tu zona:

zone "tosp.local.net" IN {
    type master;
    file "network.tosp.local.net.hosts";
};
Este bloque indica que este servidor será el maestro (master) del dominio tosp.local.net y que la configuración de los registros se encuentra en el archivo network.tosp.local.net.hosts, ubicado en /var/cache/bind/.
Archivo de zona (registros A)

Crea o edita el archivo /var/cache/bind/network.tosp.local.net.hosts con el siguiente contenido:

$TTL 300
@ IN SOA ns1.tosp.local.net. admin.tosp.local.net. (
    1       ; Serial
    10800   ; Refresh
    3600    ; Retry
    604800  ; Expire
    60      ; Minimum TTL
)

; Nameservers
@ IN NS ns1.tosp.local.net.

; Registros A — Servidores
ns1   IN A 192.168.101.20

; Registros A — Servicios
@      IN A 192.168.101.1   ; tosp.local.net → Página web
cloud  IN A 192.168.101.40  ; cloud.tosp.local.net → Nextcloud
matrix IN A 192.168.101.50  ; matrix.tosp.local.net → Matrix
Con esta configuración, el DNS resolverá los dominios locales del proyecto hacia las IPs de cada servicio dentro de la red 192.168.101.0/24.
Verificación y reinicio del servicio

Comprueba que la sintaxis del archivo de zona es correcta y reinicia el servicio:

named-checkzone tosp.local.net /var/cache/bind/network.tosp.local.net.hosts
sudo systemctl restart bind9
sudo systemctl status bind9
Si el estado muestra active (running), el servidor DNS está operativo y listo para resolver peticiones en la red local.
